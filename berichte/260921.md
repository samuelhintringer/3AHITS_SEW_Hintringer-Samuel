## C vs C#

Gibt den index der größten Zahl wieder:

```csharp
static int FindMax(int[] arr){
    int max = 0;
    for (int i = 0; i < arr.Length; i++){
        max = (arr[i] > arr[max]) ? i : max;
    }
    return max;
}
```


Gibt die größte Zahl zurück:

```csharp
static int FindMax(int[] arr){
    int max = arr[0];
    foreach (int i in arr){
        if (i > max) max = i;
    }
    return max;
}
```

## Notenliste

```csharp
class Program
{
    static void Main(string[] args)
    {
        string[] namen = {"Mayr", "Huber", "Gruber"};
        int[] punkte = {21,18,15};
        string str1;
        for ( int i = 0; i < punkte.Length; i++){
            str1 = $"{namen[i]} - {getNote(punkte[i])} ({getNoteText(getNote(punkte[i]))})";
            Console.WriteLine(str1);
        }
    }

    static int getNote(int n)
    {
        return ((n >= 12) ? ((n >= 15) ? ((n >= 18) ? ((n >= 21) ? 1 : 2) : 3) : 4) : 5);
    }

    static string getNoteText(int n)
    {
        string[] txt = {
            "Sehr Gut",
            "Gut",
            "Befriedigend",
            "Genuegend",
            "Nicht Genuegend"
        }
        
        return txt[n - 1];
    }
}
```
