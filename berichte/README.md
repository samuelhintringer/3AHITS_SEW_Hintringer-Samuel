# Dokumentation / Tagesprotokoll

Lege für jeden Termin ein Markdown File (Endung `.md`) an. Dateiname im Datumsformat `JJMMTT.md`.

Dokumentiere darin jede gemachte Übungsaufgabe, mit **Angabe**, **Code** und **Konsolenausgabe** wie im folgenden Beispiel:

## Übung - Hallo Welt

Erstelle ein C# Programm das `Hello World!` ausgibt.

Lösung:

```csharp
class Program
{
    static void Main(string[] args)
    {
        Console.WriteLine("Hello World!");
    }
}
```

Konsolenausgabe:

```
Hello World!
```

## Markdown dafür:

